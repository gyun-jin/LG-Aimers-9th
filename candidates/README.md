# Model Candidates

Make a folder for each model candidate, for example `lgbm_v1` or `catboost_v2`.
Each folder is self-contained and has its own `train.py`, `script.py`,
`requirements.txt`, and `model/model.pkl`.

When a candidate is selected, copy those three submission items into
`submission/`: `model/`, `script.py`, and `requirements.txt`.
