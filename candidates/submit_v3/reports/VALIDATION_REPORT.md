# 시간 기반 검증 보고서

## 타깃과 평가 원칙

`control_success=1`은 현재 투구가 (1) 가운데 위험 코스로 들어가지 않고, (2) 스트라이크존에서 크게 벗어나지 않고, (3) 포수 요구 방향과 반대로 들어가지 않은 유효한 제구 성공 투구라는 뜻이다. 이 세 조건은 현재 투구 뒤에 확인되는 사후 정보이므로 타깃 의미와 평가에만 사용하고 입력에는 사용하지 않았다.

공식 Brier Skill Score는 `max(0, 100000 * (1 - Brier / (r * (1-r))))`로 계산했다. 주 모델 선택에는 Accuracy를 사용하지 않았고, Brier Score, BSS, calibration, 2022~2024 안정성을 사용했다. 원시 수치와 확률 구간별 실제 성공률은 `output/validation_report.json`에 모두 저장했다.

## 앙상블과 보정

앙상블 목적함수는 최근 시즌을 중시해 `0.2*Brier(2022) + 0.3*Brier(2023) + 0.5*Brier(2024)`로 정했다.

| 구성 | 가중치 | 가중 시즌 Brier | 전체 OOF Brier | 전체 OOF BSS |
|---|---|---:|---:|---:|
| CatBoost | 1.00 | 0.247888 | 0.247309 | 1066.91 |
| LightGBM | 1.00 | 0.248601 | 0.248050 | 770.83 |
| XGBoost | 1.00 | 0.248019 | 0.247496 | 992.18 |
| CatBoost + LightGBM | 0.90 / 0.10 | 0.247883 | 0.247305 | 1068.66 |
| CatBoost + LightGBM + XGBoost | 0.60 / 0.05 / 0.35 | **0.247787** | **0.247225** | **1100.79** |
| Boosting + RandomForest | 0.57 / 0.0475 / 0.3325 / 0.05 | 0.247793 | 0.247230 | 1098.69 |

가중치는 0.05 단위 OOF 탐색으로 정했다. 3-model 앙상블이 CatBoost 단독 대비 가중 시즌 Brier를 약 0.000101 개선했고, 모델 크기와 추론 비용이 충분히 작아 최종 선택했다.

보정은 2022~2023 OOF로 학습하고 2024 OOF에 적용해 선택했다.

| 보정 | 2024 Brier | 2024 BSS | 예측 평균 | 실제 평균 |
|---|---:|---:|---:|---:|
| 없음 | 0.248141 | 667.08 | 0.49659 | 0.48610 |
| Platt | **0.247984** | **729.58** | 0.48315 | 0.48610 |
| Temperature | 0.248109 | 679.85 | 0.49639 | 0.48610 |
| Isotonic | 0.248097 | 684.53 | 0.48184 | 0.48610 |

최종 Platt 보정기는 test가 아닌 2022~2024 rolling OOF 전체로 재학습했다. 전체 OOF에서 원시 앙상블 Brier/BSS는 0.247225/1100.79, 보정 후 진단값은 0.247075/1160.68이다. 후자는 같은 OOF로 보정기를 fit한 진단값이므로 모델 선택 근거는 별도의 2024 시간 평가를 우선했다.

## 잔여 위험

시즌별 타깃 평균이 2019년 0.56467에서 2024년 0.48610으로 이동했고 2023년은 모든 모델에서 특히 어려웠다. 2025 비공개 타깃 평균의 추가 이동은 직접 검증할 수 없다. 배포 test 5행은 오직 형식·실행 검증에만 사용했으며 학습, 인코딩, 결측 대치, 보정, 가중치 선택에는 사용하지 않았다.
